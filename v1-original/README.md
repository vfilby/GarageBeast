# v1 — the original garage eye (2026-08-27)

The very first version, preserved for show and tell. Reconstructed verbatim from the
build session transcript (the project predates its git history).

A "realistic" amber eye: sclera with vignette, bloodshot veins, iris striations,
double specular highlights, round pupil. One almond shape, no styles, no sleep/wake,
no saccades — gaze glided with an exponential ease, idle look-around + blinks only.
Superseded the same day by the bold "evil ghostly" look after the rear-projection
test showed fine detail wouldn't survive frosted glass.
